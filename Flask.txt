Структура проекта:
/app
  __init__.py				# Инициализирует приложение
  views.py				# Содержит маршруты и представления
  models.py				# Содержит модели баз данных
  /static				# Файлы JavaScript, CSS и изображения
  /templates				# Шаблоны Jinja2
/
  requirements.txt			# Зависимости
  config.py				# Конфигурационные переменные и настройки
  run.py				# Точка входа для запуска приложения

Файл config.py:
import os
class Config(object):
    SECRET_KEY = os.environ.get('SECRET_KEY') or 'you_will_never_guess'
    DEBUG = False
    TESTING = False
class ProductionConfig(Config):
    DATABASE_URL = 'mysql://user@localhost/foo'
class DevelopmentConfig(Config):
    DEBUG = True
    DATABASE_URL = 'sqlite://development.db'
class TestingConfig(Config):
    TESTING = True
    DATABASE_URL = 'sqlite://testing.db'
''' Настройки: адреса баз данных, секретные ключи и т.д. '''

В файл __init__.py добавляем app.config.from_object('config.DevelopmentConfig')

Файл run.py:
from app import app
if __name__ == '__main__':
    app.run(debug=True)

Запускаем проект в консоли python run.py в виртуальном окружении

Использование разных HTTP-методов (пример):
@app.route('login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        return do_the_login()
    else:
        return show_the_login_form()

В папке templates создаем шаблон template.html:
<!DOCTYPE html>
<html>
<head>
  <title>{{title}}</title>
</head>
<body>
  <h1>Hello {{name}}!</h1>
    {% if messages %}
    <ul>
      {% for message in messages %}
      <li>{{message}}</li>
      {% endfor %}
  </ul>
  {% else %}
      <p>No messages</p>
  {% endif %}
</body>
</html>

Теперь можно использовать этот шаблон во views.py:
---пропуск---
from flask import render_template

Работа с базами данных

Устанавливаем SQLAlchemy: pip install flask_sqlalchemy

В файл __init__.py:							# А может и не в нем
from flask_sqlalchemy import SQLAlchemy
---пропуск---
app.config['SQLALCHEMY_DATABASE_URL'] = 'sqlite:///yourdatabase.db'	# Путь к БД
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False			# Выключение обработки сигналов (экономия ресурсов)
db = SQLAlchemy(app)
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)
    def __repr__(self):             					# Магический метод для отладки
        return '<User {}>'.format(self.username)

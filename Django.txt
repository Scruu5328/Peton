Редактируем views.py:
from django.shortcuts import render
from .models import Topic
def index(request):
    return render(request, 'zhopa/index.html')    
def topics(request):
    '''Выводит список тем'''
    topics = Topic.objects.order_by('date_added')
    context = {'topics' : topics}
    return render(request, 'zhopa/topics.html', context)

В той же папке, где находится index.html, создаем topics.html:
{% extends 'zhopa/base.html' %}
{% block context %}
  <p>Topics</p>
  <ul>
    {% for topic in topics %}
      <li>{{ topic }}</li>
    {% empty %}
      <li>No topics have been added yept</li>
    {% endfor %}
  </ul>
{% endblock context %}
